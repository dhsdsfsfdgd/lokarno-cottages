# Локарно — сайт аренды коттеджей (макет)

Кликабельный макет сайта загородного посёлка «Локарно»: аренда коттеджей в лесу в 30 минутах от МКАД.

**Демо:** https://dhsdsfsfdgd.github.io/lokarno-cottages/

## Что есть

- **Карта посёлка с бронированием** — схема по генплану: улицы, 69 участков, зоны отдыха. Свободные и занятые дома на выбранные даты, фильтры по гостям и типу дома, карточка коттеджа с календарём занятости и расчётом цены.
- **Заявка на бронирование** — даты, гости, доп. услуги, итог и предоплата 30%.
- **Чат с администратором** — виджет на сайте с автоответами; администратор отвечает из админ-панели.
- **Админ-панель** (`#admin`) — обзор с загрузкой и выручкой, список бронирований со статусами, шахматка, управление ценами и статусами коттеджей, чаты, настройки.
- Типы коттеджей, услуги, правила проживания, отзывы, частые вопросы, контакты.

## Важно

Это макет без серверной части: брони, цены, отзывы и переписка — демонстрационные и хранятся в `localStorage` браузера. Вход в админ-панель — демо-режим без пароля.

# Локарно — сайт аренды коттеджей (макет)

Кликабельный макет сайта загородного посёлка «Локарно»: аренда коттеджей в лесу в 30 минутах от МКАД.
Статический сайт: HTML, CSS и JavaScript без PHP, CMS и зависимостей.

**Демо:** https://dhsdsfsfdgd.github.io/lokarno-cottages/ · админ-панель: [`#admin`](https://dhsdsfsfdgd.github.io/lokarno-cottages/#admin)

## Сайт

- **Интерактивный генплан** — нарисован по схеме посёлка: 80 участков, номера, улицы и площади со схемы. При наведении — статус (свободен / забронирован / занят), тип дома, площадь участка и цена. По клику — карточка участка с контактами для брони.
- Фильтры по статусу и типу дома, счётчики свободных домов.
- Типы коттеджей, услуги, правила, отзывы, частые вопросы.
- **Без форм связи** — бронирование по телефону, в Telegram и WhatsApp.

## Админ-панель (`#admin`)

- **Генплан** — сводка по статусам и карта; клик по участку открывает редактирование: статус, тип дома, цена, описание.
- **Участки** — таблица с быстрым изменением статуса и цены, поиск и фильтры.
- **Контакты** — телефон, Telegram, WhatsApp, email, адрес; сразу обновляются на сайте.

## Важно

Это макет: статусы, цены и контакты демонстрационные и хранятся в `localStorage` браузера, вход в админку без пароля.
Для рабочей версии статусы нужно хранить на сервере или в простом хранилище, чтобы изменения администратора видели все посетители.
